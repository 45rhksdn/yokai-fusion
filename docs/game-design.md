# 게임 기획서 (현재 프로토타입 기준)

이 문서는 `index.html`에 실제로 들어 있는 규칙을 정리한 거예요. 규칙을 바꾸면 이 문서도 같이 고쳐주세요.

## 한 줄 소개

솔로몬의 72악마와 계약하고(계약 = 포획), 랜덤하게 성장시키고, 조합법으로 9왕을 불러내는 디아블로풍 방치형 게임. 플레이어는 솔로몬의 계승자인 소환사.

## 핵심 재미

1. **랜덤 성장**: 레벨업마다 성장률이 바뀌어 등급이 오르내려요.
2. **조합**: 재료 두 종류를 맞추면 신화 속 희귀 존재가 태어나요.
3. **수집**: 47종 도감과 수집 보상.
4. **자동 떼 사냥**: 디아블로풍 전투와 루팅을 구경하는 재미.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 탐험 | 자동 떼 사냥 장면, 자동 사냥 설정(루팅 필터), 난이도·지역 선택(좌우 화살표), 스테이지 진행, 팀, 탐험 기록 |
| 악마 | 보관함, 정렬, 계약 등급 확률 |
| 합성 | 합성 / 환생 전환, 조합법 목록 |
| 장비 | 장착 장비 3부위, 장비 가방 |
| 도감 | 수집 진행도, 수집 보상, 세트 보상, 47종 카드 |

헤더 아래 어두운 "방금" 띠에 직전 사냥의 경험치·골드와 최근 획득물이 흘러가요.

## 진행 구조

- 지역 7곳: 무너진 솔로몬 신전 → 잿빛 황야 → 유황 사막 → 피의 바다 → 얼어붙은 코키토스 → 불타는 심연 → 판데모니움
- 지역마다 9체: 처음부터 5체(총재·백작·후작·기사 등) + 견습생~마스터에서 1체씩(공작, 마스터는 군주)
- 지역마다 20단계. 훈련생 난이도에서 10단계를 넘으면 다음 지역 개방.
- 난이도 5단계: 훈련생 → 견습생 → 숙련자 → 전문가 → 마스터
  - 훈련생에서 모든 지역이 열리면 견습생 개방, 이후는 모든 지역 10단계 돌파 시 다음 난이도 개방.
  - 난이도가 오르면 지역마다 새 요괴 1종이 추가되고, 요구 전투력·경험치·골드·장비 등급이 올라요.
  - **포획 등급 확률은 지역·난이도와 상관없이 같아요.** 높은 난이도의 요괴가 무조건 강하지 않게 하기 위해서예요.

## 사냥 (3초마다 1회)

- 팀 전투력이 요구치 이상이면 다음 단계로.
- 요괴 발견: 3시간에 보관함 200칸이 차는 속도 (사냥 1회당 약 5.6%).
- 장비 발견: 약 1시간에 1개.
- 경험치: 팀 몬스터 3마리와 조련사가 받음. 단계마다 기본의 25%씩 증가, 난이도마다 30%씩 증가.
- 화면을 꺼두면 최대 8시간(+도감 보상)까지 숫자로 계산해 지급.

## 전투 화면 (자동 / 수동)

- **수동 조작**: 전투 화면 오른쪽 위 버튼으로 전환. 화면을 끌면 가상 조이스틱, 키보드는 WASD·방향키. 적을 톡 누르면 팀 전체가 그 적을 집중 공격. 수동으로 플레이하는 동안 경험치·골드 +25%.
- 소환사가 화면 오른쪽 끝으로 가면 지형이 흘러가며 앞으로 나아가요. 근접 악마는 소환사에게서 너무 멀리 벗어나지 않아요.

- 3D 쿼터뷰(디아블로풍). 72악마와 소환사는 부품 조합식 3D 모델(툰 셰이딩 + 잉크 외곽선)이고, 같은 모델로 카드·도감 초상화를 그려요.
- 지역마다 바닥색, 안개색, 지형 소품(신전의 무너진 기둥·촛불·인장 원, 황야의 죽은 나무·뼈, 사막의 기둥, 피의 바다, 얼음 가시와 비석, 용암 균열, 판데모니움의 흑요석 첨탑·보랏빛 화로)이 달라요.
- 조련사 주변에 일렁이는 횃불 조명, 전리품은 등급 색 빛기둥으로 표시.
- WebGL을 못 쓰면 2D 그림 장면으로 자동 전환.

- 파티가 전진하다 몬스터 떼와 부딪혀 자동 전투. 근접형은 돌진, 원거리형은 투사체.
- 적의 반격, 정예의 장판 공격, 넉백, 치명타 흔들림, 연속 처치 표시.
- 필살기: 25초마다 게이지가 차고 누르면 화면 정리 + 골드 15초분, 경험치 사냥 5회분.
- 보상 계산은 3초 사냥 틱이 담당하고, 화면은 그 결과를 보여주는 연출이에요.
- 루팅 필터: 장비·요괴 각각 기준 등급 미만은 자동 분해/놓아주기 → 골드. SS 이상 요괴는 항상 보관.

## 등급

F · E · D · C · B · A · S · SS · SR · SSR, 그 위로 각성 SSR★ · SSR★★ · SSR★★★

| 등급 | 포획 확률 |
|---|---|
| F | 약 50% |
| E | 27% |
| D | 13% |
| C | 6% |
| B | 2.6% |
| A | 0.9% |
| S | 0.3% |
| SS | 0.08% |
| SR | 0.02% |
| SSR | 0.0089% (24시간 풀가동 시 일주일에 약 1마리) |

- 등급 = 잠재력 점수 구간. 잠재력 = 현재 능력치 + 남은 레벨 동안 지금 성장률로 오를 예상치.
- 각성 ★1·★2·★3: 능력치 +10% · +30% · +50%.

## 레벨과 랜덤 성장

- 최대 100레벨. 경험치는 사냥으로만 얻음(골드로 올리지 않음).
- 레벨업마다 공격·체력·방어 성장률이 각각 변함: 15% 급성장, 15% 정체, 70% 소폭 변동.
- 소폭 변동의 중심값은 탄생 등급별로 달라서, 100레벨까지 평균 등급 변화가 아래처럼 나와요(시뮬레이션 4,000마리씩).

| 탄생 등급 | F | E | D | C | B | A | S | SS | SR | SSR |
|---|---|---|---|---|---|---|---|---|---|---|
| 평균 상승 | +2.5 | +2.15 | +1.8 | +1.45 | +1.1 | +0.75 | +0.4 | +0.05 | 0 | 소폭 하락(약 12%가 SR 이하로) |

- SSR도 하락할 수 있고, 게이지가 올라가면 각성해요.
- 사냥 중 급성장이나 등급 변화가 생기면 팝업으로 알려요.

## 합성

- 재료 2~4마리 + 골드 → 평균 등급의 새 요괴. 재료가 많을수록 대성공(+1)·초대성공(+2) 확률 증가.
- 능력치 하나에 8~30% 랜덤 보너스.
- 조합법에 맞는 두 악마가 들어가면 35%(+재료 1체당 10%p) 확률로 9왕 중 하나와 계약. 랜덤 보너스 2번.
- 왕은 재료 구하기 난이도만큼 기본 능력치 배율을 가져요(비네 ×1.36 ~ 벨리알 ×2.32). 등급과 별개로 전투력에 곱해져요.

## 환생

- 100레벨, 같은 등급 2마리 → 첫 번째가 Lv 1로 환생. 등급은 −1 / 0 / +1 (각 1/3). 최대 SSR★★까지.
- 큰 골드 비용: F 5천 · C 약 10만 · S 약 36만 · SSR 약 79만 · SSR★★★ 약 141만.

## 장비

- 무기·갑옷·장신구 3부위. 조련사에게 장착하면 전투력 추가.
- 장비도 100레벨, 레벨업마다 성장률 변화와 등급 변화. 레벨업은 골드.

## 조련사

- 사냥 경험치로 레벨업. 레벨당 기본 전투력 +6.

## 골드 사용처

합성, 장비 레벨업, 환생. (이후 콘텐츠용으로 남겨둠)
