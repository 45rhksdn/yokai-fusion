# 악마별 공격 모션

『고에티아』(레메게톤 1부)가 묘사한 모습과 능력을 바탕으로 정했어요. 코드는 `index.html`의 `STYLE_TXT`(악마별 배정)와 `MOTION`(동작 16종)·`atkFx`(효과 11종)예요.

## 동작 16종

| 동작 | 움직임 |
|---|---|
| 내리베기 | 뒤로 젖히며 비틀었다가 크게 내리벤다 |
| 찌르기 | 몸을 뒤로 뺐다가 창끝처럼 길게 찌른다 |
| 덮치기 | 웅크렸다가 뛰어올라 덮친다 |
| 들이받기 | 머리를 숙여 힘을 모았다가 멀리 돌진한다 |
| 앞발 들고 짓밟기 | 몸을 뒤로 일으켜 세웠다가 내리찍는다 |
| 급강하 | 공중으로 떠올랐다가 머리부터 내리꽂는다 |
| 회전 | 몸을 비틀었다가 한 바퀴 돈다 |
| 주문 | 몸을 젖혀 떠오르며 힘을 모았다가 앞으로 내뻗는다 |
| 똬리 틀고 물기 | 몸을 낮게 말았다가 빠르게 튀어나가 문다. 평소에도 몸을 흔든다 |
| 포효 | 고개를 숙였다가 하늘로 쳐들며 몸을 부풀린다 |
| 숨결 뿜기 | 숨을 들이쉬듯 젖혔다가 길게 뿜는다 |
| 활쏘기 | 시위를 당기듯 크게 비틀었다가 쏘고 반동으로 물러난다 |
| 물결 돌진 | 물에 뜬 듯 출렁이다가 물결처럼 덮친다 |
| 내려찍기 | 높이 솟구쳤다가 땅을 내려찍는다 |
| 훔치고 빠지기 | 아주 멀리 순식간에 파고들었다가 빠진다 |
| 순간이동 | 사라졌다가 적 앞에 나타나며 친다 |
