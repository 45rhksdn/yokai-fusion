# 악마 그림 폴더

게임은 `서열-이름.webp` 파일을 찾아 전투와 카드에 써요. 예: `01-bael.webp`, `05-marbas.webp`, `72-andromalius.webp`
(이름은 영어 고에티아 표기, `index.html`의 `SPR_DATA`에 전체 목록이 있어요.)

- 투명 배경 PNG/WebP, 세로 240px 정도, 발이 그림 아래쪽에 닿게
- 판화·고서 삽화 느낌(세피아)으로 맞추면 지금 화면과 어울려요
- **공개 저장소이므로 직접 만들었거나 라이선스가 확인된 그림만 올려주세요.**
  지금 플레이 링크(Claude 아티팩트)에 들어간 그림은 Tabirly/ars-goetia 저장소의 일러스트로, 라이선스 표시가 없어 시제품 확인용으로만 썼어요.
- 파일이 없으면 게임은 임시 인장 그림으로 대신해요.
