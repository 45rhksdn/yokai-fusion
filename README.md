# 솔로몬의 인장 (가제)

솔로몬의 마지막 후계자가 흩어진 72악마를 찾아 봉인하고, 랜덤하게 성장시키고, 조합으로 9왕을 불러내는 **디아블로풍 3D 방치형 게임** 프로토타입이에요. 1인 개발 + Claude·GPT 협업으로 만들고 있어요.

![72악마 3D 모델](art/demons-3d.png)

## 실행하기

`index.html` 파일 하나로 돌아가요. 내려받아 브라우저로 열면 바로 플레이할 수 있어요. 3D 그래픽은 인터넷에서 three.js(r128)를 불러와서 그려요. 인터넷이 안 되거나 WebGL을 못 쓰는 환경에서는 2D 그림으로 자동 전환돼요. 진행 상황은 브라우저에 저장돼요.

GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 휴대폰에서도 링크로 플레이할 수 있어요.

## 현재 들어간 기능

- 세로 전체 화면 전투 + 아래 메뉴 막대(팀·악마·합성·장비·도감·지역·설정 서랍), 소환사 주변만 밝은 디아블로식 시야
- 디아블로풍 3D 쿼터뷰 전투: 자동 사냥 + 직접 조작(조이스틱·WASD, 적 지정, 발자취를 따라오는 악마 3마리, 경험치·골드 +25%)
- 스킬 바: 소환사 '솔로몬의 인장' + 72악마 각자의 스킬 1개 (자동 모드에서도 사용)
- 스토리: 서장, 지역별 7장(도입·정복), 종장 — `docs/story.md`
- 72악마 3D 모델: 부품 조합식(머리·몸·탈것·날개·무기·왕관), 음침한 색 보정·빛나는 눈·핏빛 테두리 조명, 어두운 고딕 UI
- 7개 지옥 지역 × 20단계, 5단계 난이도
- F ~ SSR 10등급 + 각성 ★3, 레벨업마다 바뀌는 랜덤 성장
- 합성, 9왕 조합법(재료가 있으면 즉시 합성), 환생, 장비 +5 레벨업
- 장비 3부위와 장비 성장
- 도감 72체와 수집·세트 보상
- 오프라인 보상
